# assets/

壁纸与桌宠素材放在这里。**完整版仓库包含默认的 `bg-main.mp4`、`bg-4k.mp4`、`cat.png`**；`assets/uploads/` 和其它自加素材不会提交。替换素材前请确认你有权使用。

## 文件名约定

| 文件 | 作用 | 必需 |
|---|---|---|
| `bg-main.mp4` | 首选循环视频（推荐 1080p60；HEVC/H.264 均可，替换成 4K/8K 也可以） | 否 |
| `bg-4k.mp4` | 4K/8K 备选；自动选择仍优先 `bg-main`，想要最高画质请直接在壁纸面板点它 | 否 |
| `cat.png` | 桌宠形象，透明背景 PNG，建议 1130×569 | 否 |
| 任意 `*.mp4 / *.webm / *.mov / *.m4v` | 其它视频壁纸，会出现在壁纸面板的清单里 | 否 |
| 任意 `*.png / *.jpg / *.jpeg / *.webp / *.avif / *.gif / *.svg` | 静态壁纸，同样会出现在清单里 | 否 |

## 自动选择顺序

1. 用户在壁纸面板里选择过的文件（记录在浏览器 `localStorage`）
2. `bg-main.mp4`
3. `bg-4k.mp4`
4. `assets/` 中其它视频（按文件名排序）
5. `assets/` 中第一张图片
6. 内置天光渐变

`cat.png` 永远不参与壁纸候选。

编码探测不再按文件名猜：如果 `bg-main.mp4` 实际是 H.264 4K/8K，浏览器会正常尝试；解码失败才自动退到 `bg-4k` / `bg-1080`。

## 上传与场景

- `assets/uploads/`：面板「上传壁纸」写入的图片/视频，**属于用户数据，不属于发布包，也不提交到仓库**；自动创建，同名自动加 `-1`，不会覆盖；单文件默认 ≤512MB（`TIANLIGHT_UPLOAD_MAX` 可调）。
- WE 场景**不放在这里**：壁纸面板 → Wallpaper Engine 里配置 roots，宿主会扫描含 `project.json` 的子目录；场景由 `vendor/webwallgl/` 的引擎在沙箱 iframe 里渲染。

## 注意

- 没有视频也没有图片时，皮肤仍可正常使用，只是显示内置渐变
- 图片壁纸会以 `cover` 铺满，取色面板对**同源**图片有效；跨域图片因画布污染会保持默认配色
- 壁纸面板顶部会显示「源分辨率 / 当前裁切尺寸」：低于窗口设备像素时会提示可能发糊
- 8K 源可能被浏览器自动降采样；4K 在集显机器上也可能掉帧，建议按机器性能选择
- 自动选择优先 `bg-main` 是为了兼容性；要 4K/8K 清晰度请直接点对应卡片
- 宿主的 MIME 已覆盖 `.mov / .m4v / .avif / .gif`
