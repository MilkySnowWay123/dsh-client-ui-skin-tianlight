# 精选配方

面板「配方」段内置 5 个精选配方，直接用卡片套用，不联网：

| 卡片 | 内容 |
|---|---|
| 极光 · 暗角 | ShaderToy 极光 + 暗角，附带取景/玻璃/省电 |
| 音频极光 · 扫描线 | 音频极光 + 扫描线/光晕；麦克风仍需手动启用 |
| 电影感 · 颗粒 | 保留当前壁纸，只叠颗粒 + 暗角 |
| 冷夜 · 光晕 | 保留当前壁纸，叠光晕 + 扫描线 |
| 纯净 | 清空两层叠加 |

## 文件说明

- 面板里的内置列表是**规范来源**（在 `src/70-sidebar.js` 的 `CURATED_PRESETS`）。
- 这里的 JSON 是可分享的外观配方副本；着色器配方（极光/音频极光）带完整 GLSL 源码，直接从面板「导出配方」复制即可。
- 所有配方都是 `tianlight-preset` v1，可粘贴进面板「导入配方」；`layers` 使用 v2 双槽结构。
- 不联网、不上传、不收集数据。
