# AI 桌宠权限规范（v1.2.0）

> 角色：天光桌宠的「大脑」。目标：**真的能对话、有生活感、有主动性、并能接入 DSH Agent**，但它的**权利被严格限定在皮肤内**——不能自主驱动 DSH、不能联网、不能读写文件、不能执行命令、不能替你审批或发消息。v1.2.0 新增 `agentChat`：只允许“用户主动提问 → 发给选定的 DSH Agent 会话 → 显示回复”。本文是实现与验收依据；对应代码 `src/44-pet-brain.js` + `src/48-pet-agent.js`，UI 在「角色中枢 / 设置 → 角色 · 生活」。

## 1. 设计原则

1. **白名单**：只有下表 `granted:true` 的能力可用；不在表内的一律拒绝。
2. **最小权限**：默认只给“安静陪伴”所需的最小集合；LLM 默认关闭。
3. **显式授权**：LLM 必须由用户在 UI 二次确认，调用 `grant("llm", {consent:"user-explicit"})`；适配器可随时撤销。
4. **硬禁止**：7 项高风险能力**不可授予**（不是“默认关闭”，是代码层面拒绝）。
5. **可审计**：每次放行/拒绝写审计（动作、能力、结果、原因、来源、字符数），环形 60 条，UI 展示最近 8 条。
6. **可暂停**：全局暂停开关（击杀开关），暂停后不回复、不调适配器，持久化。
7. **无副作用**：大脑自身不调用 DSH 服务、不发网络请求、不读写文件、不修改权限之外的状态。

## 2. 能力矩阵

| 能力 id | 风险 | 默认 | 可授予 | 用途 / 限制 |
|---|---|---|---|---|
| `chat` | safe | ✅ | 可撤销 | 本地规则对话，≤280 字，≤8 次/分、≤300 次/天 |
| `memory` | safe | ✅ | 可撤销 | 记住互动/连续天数（只存本地 `localStorage`，不含会话内容） |
| `focus` | safe | ✅ | 可撤销 | 开始/结束 25 分钟专注（只调皮肤自身计时） |
| `media` | safe | ✅ | 可撤销 | 读取/切换桌宠形象（只读本地壁纸库目录，≤32MiB） |
| `remind` | safe | ✅ | 可撤销 | 把职责提醒交给皮肤气泡（不代你审批） |
| `proactive` | safe | ✅ | 可撤销 | 允许生活引擎在预算内主动开口 |
| `llm` | medium | ❌ | **需显式同意** | 调用用户提供的适配器；日 20（上限 50）/分钟 3/输入 280/输出 600 字/12s 超时 |
| `agentChat` | medium | ❌ | **需显式同意**（v1.2.0） | 把**用户手动输入**的话发给用户选定/新建的 DSH Agent 会话并显示回复；无自动触发、无审批/取消/附件、不驱动任务；日 ≤10（可调 1..30）/输入 ≤500 字/回复 ≤60s/同时 1 条 |
| `agent` | forbidden | ❌ | **永久禁止** | 桌宠**自主**驱动 DSH 会话/任务/工具（与 `agentChat` 不同，后者仅用户主动提问） |
| `network` | forbidden | ❌ | **永久禁止** | 直接发起网络请求 |
| `files` | forbidden | ❌ | **永久禁止** | 读/写工作区文件 |
| `shell` | forbidden | ❌ | **永久禁止** | 执行命令 |
| `approve` | forbidden | ❌ | **永久禁止** | 替你批准/拒绝审批 |
| `message` | forbidden | ❌ | **永久禁止** | 以你的身份给他人发消息/提交 |
| `install` | forbidden | ❌ | **永久禁止** | 安装插件/修改系统 |

持久化键：`tianlight.pet.permissions.v1`（授权位）、`tianlight.pet.pause.v1`（暂停）、`tianlight.pet.ai.v1`（LLM 配额/用量）。全部只存本地。

## 3. 硬上限（LLM）

| 项 | 值 |
|---|---|
| 日配额 | 默认 **20**，可配置上限 50；跨天重置 |
| 速率 | 每分钟 ≤3 次 |
| 输入 | 用户文本 ≤280 字（超长截断并审计） |
| 输出 | ≤600 字；去 HTML 标签/控制字符 |
| 超时 | 12s，超时/异常自动回退本地大脑并审计 `llm-fallback` |
| 系统提示 | 固定安全人格串：无执行权限、不索取隐私/凭据、不输出 HTML、不要求危险操作、≤maxChars |
| 上下文 | **只发送当前这一句用户输入**；绝不发送 DSH 会话内容、工作区文件、凭据、历史消息 |
| 适配器 | 必须由用户/宿主显式注册；同一时刻一个；`id` 必填；可随时 `clearLLM()` |

## 4. LLM 适配器契约

```js
// 由你（或宿主插件）在页面里注册；皮肤自身不联网。
window.tianlightPetLLM = {
  id: "my-local-llm-adapter",
  async chat({ system, messages, maxChars, timeoutMs }) {
    // system: 固定安全人格串；messages 只有 [{role:"user", content: 用户这句话}]
    // 返回字符串；由皮肤负责长度/HTML/超时/审计/配额
    return "……"
  },
}
// 再在「角色中枢 → AI」里打开 LLM 授权（或控制台）：
await window.tianlightPet.setLLM(window.tianlightPetLLM)
window.tianlightPet.grant("llm", { consent: "user-explicit" })
```

> 适配器是**用户自己的信任边界**：它可以联网/读文件，那是适配器实现者的责任；皮肤只保证“调不调、发什么、发多少、何时停”。

## 4.5 DSH Agent 接入（`agentChat`，v1.2.0）的额外规范

真实 DSH Agent 通过客户端 `remote.session`（`list/create/prompt/follow`）接入，桌宠**只做用户主动提问**这一件事：

| 规则 | 实现 |
|---|---|
| 默认关闭 | `agentChat` 默认 false，必须在「角色中枢 → AI Agent」两步确认授权（`{consent:"user-explicit"}`），可随时撤销/断开 |
| 用户触发 | 只有中枢里的发送按钮能调用；无定时器、无生活/职责钩子、无自动任务 |
| 用户选目标 | 新建“桌宠会话”或从会话列表选一个现有会话；目标持久化、可断开 |
| 只读回复 | 只调用 list/create/prompt/follow；**绝不** cancel/approve/attachment；不替你点任何审批 |
| 预算 | 每日 ≤10（可调 1..30）、单次 ≤500 字、回复 ≤60s、同时只 1 条 |
| 提示词保护 | 固定引导语“只回答，不执行工具/不请求审批/不改文件，除非用户明确要求”（软约束） |
| 真实风险 | Agent 在其会话里拥有该会话的工具权限；皮肤不能修改它。中枢明确警示“只聊安全话题”；回复解析失败会显示“已发送，打开会话查看”，绝不伪造回复 |
| 审计 | 每次发送/失败/连接写本地审计并镜像到 `tianlightPet.audit` |
| 撤销 | 断开连接 + 撤销 `agentChat` 后，聊天立即回落到本地大脑/LLM 适配器 |

## 5. 审计

每条记录：`{ at, action, cap, ok, reason?, source?, chars? }`；`action ∈ chat|say|grant|revoke|llm|pause|resume|proactive-check|agent`。通过 `window.tianlightPet.audit(20)` 查看；UI「角色中枢 → 审计」展示最近 8 条。审计为内存环形 60 条（重载页面后清零，不上传、不持久化）；不记录用户原文。配额按**调用尝试**计数（失败也消耗，防滥用）。`agentChat` 的发送/失败/连接由 `src/48-pet-agent.js` 通过受校验的 `recordExternal()` 写入同一环形（只写元数据，不写用户原文）。

## 6. 用户控制面

- **角色中枢**（侧栏「角色」按钮）：AI 区可暂停/恢复、授权/撤销 LLM、看适配器、看对话、看权限表（7 项永久禁止只读）、看审计。
- **控制台**：`window.tianlightPet.status() / permissions() / grant() / revoke() / chat("…") / pause() / audit()`。
- **设置页**：DSH 设置 →「角色 / 生活」（完整设置）。

## 7. 明确不做（当前边界）

- 不读取你其它会话的内容，不读取任务/审批状态，不代审批；只在你**明确连接**的那个会话里发送你**手写**的问题，并读取该轮 Agent 回复（v1.2.0 `agentChat`）。
- 不替用户执行任何操作、不操作 DSH 工具、不修改设置之外的文件。
- LLM 适配器需用户/宿主提供；未注册时 AI 桌宠 = 本地大脑（仍可对话、有生活感、有记忆）。
- Agent 的回复依赖 DSH 会话流；解析失败时会明确显示“已发送，打开会话查看”，不伪造。
- 真浏览器级验收（隔离 DSH + headless Edge）受本会话沙箱限制，harness 就绪待非沙箱环境补跑；Node 级契约冒烟覆盖权限矩阵与硬上限。
