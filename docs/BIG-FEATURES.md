# 大件功能 · 设计与顺序

状态：图层合成 v1/v2、音频可视化 v1、本地精选配方市场 v0.1、自动轮播、隐藏/上传、WebWallGL 场景接入已完成；真在线市场需要后端。每一步都独立构建、独立验收、随时回滚。

## 顺序与理由

1. **图层合成 v1** —— 纯本地、无权限、无后端；能直接复用现有场景和 CSS，风险最低，先做。
2. **音频可视化** —— 需要用户授权麦克风/系统音频，隐私与失败路径必须先设计清楚，放在图层之后。
3. **市场** —— 真市场需要托管目录与审核；先做本地「精选配方」，不假装有后端。

## 1. 图层合成

### 目标

在现有壁纸之上叠加可调层，不增加第二个视频解码器，不打断 ShaderToy / 视频 / 静态帧。

### v1（已完成）

- 归属：**外观**段「叠加层」子块，不新增第七段，保持六段结构。
- 预设：`无 / 暗角 / 胶片颗粒 / 渐变光 / 扫描线`。
- 参数：不透明度 0–100%、混合模式 `正常 / 叠加 / 滤色 / 正片叠底`。
- 持久化：`tianlight.layers`；配方导入/导出也带这一项。
- 实现：场景内一个 `[data-tl-overlay]` 层 + CSS 变量；预设用 CSS 渐变/重复图案，无新 canvas、无新定时器。
- 低功耗：静态叠加层不受影响；低功耗直接冻结。
- 验收：五种预设肉眼可辨；切视频/图片/Shader 后叠加仍在；刷新保持；关皮肤后 `data-tl-*` 无残留。

### v2（已完成）

- 第二个叠加槽、图片叠加（本地/URL）、适配方式、A/B 交换层级。
- 旧 v1 单对象自动迁移到 A 槽；配方导入兼容。
- 叠加层不参与面板取色，避免颜色反馈环。

## 2. 音频可视化

### 前置约束

- **必须用户显式点击开启**，不自动请求麦克风/屏幕音频。
- 只做实时分析，不录音、不上传、不持久化音频数据。
- 失败路径：拒绝授权、无设备、浏览器不支持，都要有明确提示并保持当前壁纸。

### v1（已完成）

- 麦克风 → WebAudio `AnalyserNode` → 平滑后的整体电平 `u_audio`（v1 不做频段/节拍）。
- ShaderToy 新增 `u_audio` uniform；内置「音频极光」预设。
- 页面隐藏、低功耗、关闭面板、切走 ShaderToy 时停止分析并释放 `MediaStream`。
- 只在 ShaderToy 壁纸激活时允许启用；拒绝授权/无设备/无 WebAudio 都有明确提示。

### v2

- 系统音频（`getDisplayMedia({ audio: true })`），仍由用户手势触发。
- 节拍检测与更强的可视化预设。

## 3. 市场

### 本地精选 v0.1（已完成）

- 面板「配方」段内置 5 张卡片，一键套用；不联网、不收集数据。
- `presets/*.json` 提供可分享的外观配方副本；着色器配方从面板「导出配方」复制。
- 旧配方仍可导入/导出，`layers` v2 兼容。

### 诚实边界

没有托管目录、账号、审核与 CDN，做不出真正的在线市场。真市场需要：

- 托管 API（列表/详情/下载计数）、内容审核、版本兼容字段、失败降级。
- 这些需要单独的后端决定，不在皮肤插件内硬造。

## 4. 自动轮播与壁纸库（已完成）

- 模型：`tianlight.rotation = {on, order, interval, favoritesOnly}`；UI 在 ⑤ 性能。
- 只在页面可见、未省电、未手动暂停时推进；`prepareWallpaper()` 先解图片/取视频元数据，再换源。
- 隐藏：`tianlight.library.items[url].hidden`；轮播候选与清单同时生效；隐藏当前壁纸不打断播放。
- 上传：宿主 `lib/upload.js`，512MB 流式上限、安全文件名、`.part-*` → rename、同名序号；面板入口在 ② 清单。

## 5. WebWallGL 场景（P3，已接入）

### 边界

- 引擎是**可选依赖**：`vendor/webwallgl/`（MIT，3.0），不内联进 `client.js`；宿主缺文件时 `_engines` 报 `webwallgl:false`。
- 场景只收 `project.json` + `scene.pkg`（或松散 `scene.json`）的 `type:"scene"` 项目；网页壁纸、系统音频、ffmpeg 转码不在本轮。

### 安全

- 客户端 `<iframe sandbox="allow-scripts">` + 宿主 CSP `sandbox allow-scripts` → opaque origin，场景脚本够不到宿主 DOM。
- 场景文件逐段 `SAFE_NAME` + 解析后包含 + 扩展名白名单；只对该路由给 CORS。
- 父页面只接受 `event.source === iframe.contentWindow` 且 `__tlScene === true` 的消息。

### 失败与性能

- 首帧预算 20s；`error` → 上一张可播 → 自动选择 → 渐变。
- 适配页每秒上报 `stats.fps`，父页面写 `data-tl-fps`；6s 无上报 → `stalled`，面板给「重试」。
- 暂停/省电/页面隐藏通过 postMessage 停引擎；恢复时 `resume`。
