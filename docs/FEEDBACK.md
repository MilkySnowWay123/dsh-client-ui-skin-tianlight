# 反馈渠道 / Feedback

## 在哪里反馈

- **GitHub Issues（推荐）**：<https://github.com/MilkySnowWay123/dsh-client-ui-skin-tianlight/issues>
  - 新建议题时选择「反馈 / Feedback」模板；桌面端不需要账号也能查看，提交需要 GitHub 账号。
- **应用内反馈面板（v1.5.0 起）**：打开角色中枢（**右键桌宠** / 桌宠菜单「角色中枢」）→「**反馈**」面板：
  - **复制**：把环境 + 功能状态 + 你的备注复制到剪贴板，可直接粘贴到 Issue；
  - **打开 Issue**：一键打开预填了标题/正文的 GitHub 新建议题页（你仍可在提交前修改）；
  - **下载 JSON**：把反馈数据保存为 `tianlight-feedback-<时间>.json`，适合离线或邮件提交。
- 反馈面板会自动带上：天光版本、DSH/浏览器信息、桌宠生活/权限/AI Agent/玻璃/天气的当前状态摘要（不包含对话内容与凭据）。

## 需要附上什么

1. 天光版本（`CHANGELOG.md` / 角色中枢）；
2. DSH 版本与平台（Windows/macOS/Linux，Desktop 或 Web）；
3. 复现步骤：预期 → 实际；
4. 与视觉有关时：角色中枢里看到的玻璃档位/实际档位、 wallpaper 是否启用、是否低电量/15fps 降级；
5. 与天气有关时：是否已启用天气、城市/坐标是否已设置、天气卡显示的状态文案；
6. 与桌宠形象有关时：当前形象 id 或「恢复默认形象」是否可点。

## 隐私与安全

- **不要**粘贴 API key、Token、密码、私人文件内容；
- 反馈面板只读取功能状态与版本，不读取会话正文；
- 如涉及权限能力适配器，请只描述能力名，不要贴适配器密钥。

## 维护者处理约定

- 带 `feedback` 标签的 Issue 会尽快分类；功能不生效类优先要求「自检」结果（角色中枢 → 自检 → 复制）；
- 需要日志时请提供角色中枢「自检」与反馈 JSON，而不是整份配置文件。
