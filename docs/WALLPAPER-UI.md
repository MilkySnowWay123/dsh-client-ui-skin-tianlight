## 四、状态模型（单一来源）

```js
zones     = { separate, main: {fit,fx,fy,dim,blur,ratio,zoom,cx,cy}, rail: {fit,fx,fy,dim,blur,url,kind} }
glass     = 0.35 … 1.5          // 全局倍率
lowPower  = "auto" | "on" | "off"
choice    = { kind, url, still? } | null  // 当前壁纸；still = 静态帧秒数；null = 自动
renderTier = "auto" | "60" | "30" | "15"    // ShaderToy / 侧栏镜像档位；视频按源帧率
layers    = { version, slots: [A, B] }   // 每槽 { kind, preset, url, fit, opacity, blend }；v1 单对象自动迁移到 A
playback  = { speed, flip, paused, filter: { on, brightness, contrast, saturate } }
rotation  = { on, order: "sequence"|"random", interval, favoritesOnly }
audio     = { active, busy }             // 仅运行时；不持久化，必须用户点击才请求麦克风
sourceTab = "local" | "url" | "we" | "shader"   // 来源真 tab（仅 UI 态）
library   = { items: { [url]: { favorite, tags, hidden } } }
shader    = { preset, source, speed, intensity, hue }
```

持久化键：`tianlight.zones` / `tianlight.glass` / `tianlight.lowpower` / `tianlight.fps` / `tianlight.wallpaper` / `tianlight.library` / `tianlight.shader` / `tianlight.layers` / `tianlight.playback` / `tianlight.rotation` / `tianlight.font.family` / `tianlight.font.position` / `dsh-tianlight:cat:v1`。
**约束**：所有写入走各自的 controller（`zoneController` / `glassController` / `lowPowerController` / `wallpaperController` / `wallpaperLibraryController` / `layerController` / `playbackController` / `rotationController`），组件不直接碰 `localStorage`。

## 六、验收标准（每次改动）

```bash
node tools/build.mjs --check
node tools/test.mjs && node tools/structure.mjs --strict
node tools/audit.mjs && node tools/check-css.mjs && node tools/verify.mjs
```

外加人工确认：
- 点每个来源按钮，清单内容与该来源一致：本地只显示 assets/、WE 只显示目录条目、URL 标签页显示 URL 输入、Shader 标签页显示 GLSL 编辑器
- 清单搜索、收藏、标签筛选可组合，「清除筛选」能复位
- ShaderToy：选预设 / 改速度强度色相后点「应用着色器」画面变化；错误源码只显示编译错误，不替换当前壁纸
- ShaderToy 低功耗时停帧（rAF 停止），关掉后恢复；切回视频/图片正常，面板取色跟随 GLSL 画面
- 静态帧：显式选视频 → 生成帧预览 → 点一帧，画面停在该帧；「回到动态」恢复；重载后仍保持
- 跨域 URL 视频取帧会提示浏览器禁止（本地 / WE 视频正常）
- 帧率档位切 15 后 ShaderToy 明显降到 15fps、侧栏镜像约 6fps；视频播放不受影响；省电设置仍优先
- 60fps 档只影响 ShaderToy 与镜像，60 更耗电；视频按源帧率原生播放，60fps 源不需要设置
- 刷新后若停在静态帧、省电暂停或浏览器拦截自动播放，顶部会出现真实状态与「回到动态 / 关闭省电并播放 / 播放动态 / 重试」入口
- 播放状态：顶部圆点与文案必须和画面一致（播放中/已暂停/被拦截/省电/静态帧/卡住/失败）；任意点击或按键后自动播放限制被解除；从后台切回、窗口聚焦会重试
- 暂停：取景段「暂停动态」刷新后仍保持暂停，顶部「继续播放」可恢复；省电触发不会覆盖手动暂停
- 滤镜：默认关闭时 `[data-tl-filter]` 不存在（无全屏 filter 路径）；开启后亮度/对比度/饱和度生效；关闭立即回到无滤镜路径
- 轮播：开启后按间隔切到下一张，当前这张不重复；页面隐藏/省电/暂停时顺延；隐藏的壁纸和坏文件不参与；只轮播收藏时只选收藏
- 壁纸库：隐藏只改列表，不删除文件、不打断当前播放；「显示隐藏」能恢复；卡片显示类型与文件大小
- 上传：≤512MB 的图片/视频可上传并在清单出现；同名自动加 `-1`；非图片/视频扩展名、超限、空文件被拒绝；中文文件名会清洗成可播放的 ASCII 名
- 场景：WE 目录里 `project.json` + `scene.pkg` 出现在 WE 清单；点击后沙箱 iframe 渲染；引擎缺失/首帧超时会提示并退回上一张可播壁纸；暂停/省电时 iframe 停止渲染
- 当前（190410）：默认「选壁纸」是统一混合库，顶部 `全部/本地/WE` 筛选 + 网址/WE 目录/GLSL 导入链接；点缩略图立即应用，画面/外观/自动/保存收进「高级」
- 导入：网址自动聚焦输入框；WE 筛选为空时自动展开「配置目录」
- WE：配置入口在 WE 清单顶部；不需要先找到来源卡
- 简单视图不显示收藏/标签/隐藏管理（这些在「高级」里的完整清单中）；从高级切回选壁纸会清空筛选，避免列表看起来是空的
- URL：点「网址导入」自动聚焦；有扩展名直接应用，无扩展名先试图片再试视频；非直链会显示原因且不替换当前壁纸；HTTPS 页面拒绝 http 地址
- 不抖：播放中质量行固定单行（省略号），FPS 每 1.8s 才更新；面板打开只取色两次；拖动后在窗外松手、或单击标题，面板不会自己移动
- 空状态：没有壁纸时给出上传入口；WE 为空给「配置 WE 目录」按钮
- 顶部保留播放状态、当前壁纸与画质行；异常/暂停时可操作
- 叠加层：暗角/颗粒/光晕/扫描线在视频、图片、Shader 上都能切换；不透明度/混合生效；刷新保持
- 叠加层 v2：A/B 两槽可分别设为预设或图片，支持本地图片/URL、填满/完整/拉伸、交换层级；旧 v1 设置自动迁移到 A
- 音频：必须手动点「启用麦克风」；只分析不录音；关闭面板/省电/切走 ShaderToy/页面隐藏都会停止并释放麦克风
- 配方：5 个精选卡片可一键套用（极光暗角/音频极光/电影颗粒/冷夜光晕/纯净）；`presets/` 有可分享副本
- 画质：顶部显示源分辨率、当前裁切尺寸与实测视频 FPS；720p 在 1080p 窗口会提示可能发糊，4K 不提示；8K 另有降采样提醒
- 播放：取景段可暂停/播放、0.5–1.5x 倍速、水平翻转；倍速按比例改变实际帧率，60fps 源不额外封顶
- 拖动：只有顶部标题/引导区是拖拽把手，面板主体用鼠标滚轮/触摸正常滚动；关闭按钮不触发拖动
- 独立侧栏关闭时镜像的 rAF 循环不启动；开启时才按档位绘制，少占主视频的帧预算
- 格式：URL 可强制「图片/视频/自动」；无扩展名地址自动探测；视频/图片解码失败会回退到上一张可播画面
- 关闭面板再打开，所有状态保持
- 省电=开（或自动触发）时动态壁纸停在当前帧，关掉后恢复；图片壁纸下不会偷偷解码视频
- 关皮肤后 `body` 上不留 `data-tl-*` / `--tl-*` 残留
